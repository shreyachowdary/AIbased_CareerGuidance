# AI Career Guidance System (MVP)

An AI-driven personalized career guidance prototype: ingest user profile and job postings, extract skills, recommend top-N jobs by TF-IDF + cosine similarity, and perform skill-gap analysis with a learning roadmap placeholder.

## Project structure

```
CapProject/
├── backend/           # FastAPI app
│   ├── main.py        # Endpoints: GET /health, POST /recommend
│   └── services/      # ingestion, skill_extraction, recommend, gap_analysis
├── app/               # Streamlit UI
│   └── streamlit_app.py
├── data/              # Job dataset
│   ├── jobs.csv       # Sample job postings (required columns: job_id, title, description)
│   └── README.md      # CSV format description
├── models/            # Saved TF-IDF vectorizer + job vectors (generated by script)
├── scripts/           # Offline preprocessing
│   └── build_vectors.py
├── requirements.txt
└── README.md
```

## How to run locally

### 1. Create virtual environment and install dependencies

```bash
cd CapProject
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
# source venv/bin/activate
pip install -r requirements.txt
```

### 2. Build job vectors (required once)

From the **project root** (`CapProject`):

```bash
python scripts/build_vectors.py
```

This reads `data/jobs.csv`, builds the TF-IDF vectorizer and job vectors, and saves them under `models/`.

### 3. Start the backend

From the project root:

```bash
uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

- API: <http://127.0.0.1:8000>
- Docs: <http://127.0.0.1:8000/docs>

### 4. Start the Streamlit UI

In a **second terminal**, from the project root:

```bash
streamlit run app/streamlit_app.py
```

Open the URL shown (e.g. <http://localhost:8501>). Enter education, skills, interests, desired role, then click **Get Recommendations**.

## API

- **GET /health** — Returns `{"status": "ok", "models_loaded": true/false}`.
- **POST /recommend** — Body: `{"skills": "...", "education": "...", "interests": "...", "desired_role": "..."}`. Query param: `top_n` (default 10). Returns ranked jobs with `similarity_score`, `matched_skills`, `missing_skills`, and a learning-roadmap message.

## Smoke test

From the project root (after building vectors and with backend running):

```bash
python scripts/smoke_test.py
```

Or run pytest (if you add tests under `tests/`):

```bash
pytest tests/ -v
```

## Data format

CSV in `data/jobs.csv` must have at least: `job_id`, `title`, `description`. Optional: `company`, `skills` (comma-separated). If `skills` is missing, skills are extracted from the description during preprocessing.

## Tech stack (MVP)

- **Backend:** Python, FastAPI  
- **Frontend:** Streamlit  
- **ML:** scikit-learn (TF-IDF + cosine similarity)  
- **Skill extraction:** Keyword/dictionary-based (see `backend/services/skill_extraction.py`)

No external paid APIs; all processing is local and deterministic.
